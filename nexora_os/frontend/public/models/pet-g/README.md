# Pet G Blender model

This folder contains the Pet G companion model package.

## Files

- `make_pet_g_blender.py` — authoritative Blender generator.
- `pet_g.blend` — generated by Blender when Blender is installed.
- `pet_g.glb` — runtime-ready GLB generated by Blender.
- `pet_g_preview.png` — preview render generated by Blender.
- `generate_pet_g_obj.py` — fallback mesh generator that does not require Blender.
- `pet_g.obj` / `pet_g.mtl` — fallback static mesh generated locally.
- `pet_g_manifest.json` — model metadata.

## Generate with Blender

Do not use the raw `blender --background ...` command unless Blender is already
installed and available on your PATH. On Windows, use the local runner because it
auto-detects common Blender install folders and prints a clear fix when Blender
is missing.

From this folder:

```powershell
.\run_pet_g_blender.ps1
```

From the repository root:

```cmd
create_pet_g_blender_model.cmd
```

If Blender is not in `PATH`, use the full Blender executable path:

```powershell
& "C:\Program Files\Blender Foundation\Blender 4.2\blender.exe" --background --python make_pet_g_blender.py
```

Or pass the path to the helper:

```powershell
.\run_pet_g_blender.ps1 -BlenderPath "C:\Program Files\Blender Foundation\Blender 4.2\blender.exe"
```

If Blender is not installed:

```powershell
winget install --id BlenderFoundation.Blender -e
```

## Design

Pet G is a small friendly graphite robot companion with:

- soft capsule body;
- round display head;
- cyan glowing eyes and antenna lights;
- amber `G` chest mark;
- titanium hands/feet;
- small display base.

Use `pet_g.glb` in the frontend once generated. `pet_g.obj` is a static fallback only.
